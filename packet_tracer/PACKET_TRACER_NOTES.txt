1. TOPOLOGY DESCRIPTION
-------------------------------------------------------------------------------
The NetSage AI demonstration topology represents a modern, standard 2-VLAN
Enterprise Branch Office utilizing Router-on-a-Stick inter-VLAN routing.

Device Layout:
- 1 Router  : R1 (Cisco 2911 / 4331 Router)
- 1 Switch  : SW1 (Cisco Catalyst 2960 Switch)
- 1 Server  : Server-1 (Services / DNS Server on VLAN 10)
- 3 PCs     : PC-1 (VLAN 10 Sales), PC-2 (VLAN 10 Sales), PC-3 (VLAN 20 Eng)

Physical Connections:
- R1 (GigabitEthernet0/0/0) <---> SW1 (FastEthernet0/24) [802.1Q Trunk]
- SW1 (FastEthernet0/1)   <---> PC-1 (Sales User 1)      [Access VLAN 10]
- SW1 (FastEthernet0/2)   <---> PC-2 (Sales User 2)      [Access VLAN 10]
- SW1 (FastEthernet0/3)   <---> PC-3 (Engineering User)  [Access VLAN 20]
- SW1 (FastEthernet0/10)  <---> Server-1 (Internal Server)[Access VLAN 10]


-------------------------------------------------------------------------------
2. DEVICE NAMES
-------------------------------------------------------------------------------

- SW1      : Access Layer Switch
- PC-1     : Sales Workstation 1

- Server-1 : Enterprise DNS / Web Server

- Fa0/3  : Access VLAN 20 (PC-3)
- Fa0/10 : Access VLAN 10 (Server-1)
- Fa0/24 : Trunk Mode 802.1Q (Connected to R1 G0/0/0)


-------------------------------------------------------------------------------
5. COMMANDS TO VERIFY THE NETWORK
-------------------------------------------------------------------------------
On Switch SW1:
  SW1# show vlan brief
  SW1# show interface status
  SW1# show interface trunk

On Router R1:
  R1# show ip interface brief
  R1# show ip route
  R1# show ip arp

On PCs / End Hosts (Command Prompt):
  ipconfig /all
  ping 192.168.10.1     (Test local gateway ping)
  ping 192.168.20.10    (Test inter-VLAN ping from PC-1 to PC-3)
  ping 192.168.10.254   (Test server connectivity)


-------------------------------------------------------------------------------
6. HOW TO REPRODUCE CASE 1 — VLAN MISMATCH
-------------------------------------------------------------------------------
Scenario: PC-1 is assigned IP 192.168.10.10 (VLAN 10 subnet), but its switchport
Fa0/1 is incorrectly configured for VLAN 20.

Step 1: Open SW1 CLI in Packet Tracer.
Step 2: Execute the fault injection commands:
          SW1# configure terminal
          SW1(config)# interface FastEthernet0/1
          SW1(config-if)# switchport access vlan 20
          SW1(config-if)# end
Step 3: Test ping from PC-1 Command Prompt:
          ping 192.168.10.1  --> (Fails with Request Timed Out)
Step 4: Execute Cisco show command to generate evidence for NetSage AI:
          SW1# show interface FastEthernet0/1 switchport
        Notice: Access Mode VLAN: 20 (Mismatch with PC IP Subnet 10!)


-------------------------------------------------------------------------------
7. HOW TO REPRODUCE CASE 8 — DUPLICATE IP ADDRESS
-------------------------------------------------------------------------------
Scenario: PC-2 is accidentally configured with IP 192.168.10.10, creating an IP
address conflict with PC-1.

Step 1: Open PC-2 in Packet Tracer -> Desktop -> IP Configuration.
Step 2: Change IP address from 192.168.10.11 to 192.168.10.10.
Step 3: Try pinging gateway 192.168.10.1 from PC-1 and PC-2 simultaneously.
Step 4: Observe intermittent packet drops and ARP flapping.
Step 5: Execute Cisco verification command on R1:
          R1# show ip arp
        Notice: Duplicate IP 192.168.10.10 flapping between two MAC addresses!


-------------------------------------------------------------------------------
8. HOW TO REPRODUCE CASE 10 — GATEWAY SUBNET MISMATCH
-------------------------------------------------------------------------------
Scenario: PC-1 has IP 192.168.10.10/24, but its default gateway is set to
192.168.20.1 (a completely different subnet).

Step 1: Open PC-1 in Packet Tracer -> Desktop -> IP Configuration.
Step 2: Change Default Gateway from 192.168.10.1 to 192.168.20.1.
Step 3: Test ping from PC-1 Command Prompt:
          ping 192.168.20.10 --> (Fails - Destination Host Unreachable)
Step 4: Execute verification command on PC-1:
          ipconfig /all
        Notice: IP is 192.168.10.10, but Gateway is 192.168.20.1 (Subnet mismatch!)


-------------------------------------------------------------------------------
9. HOW TO RESTORE THE NETWORK TO CLEAN / CORRECT STATE
-------------------------------------------------------------------------------
To restore all devices to 100% operational state:

On Switch SW1:
  SW1# configure terminal
  SW1(config)# interface FastEthernet0/1
  SW1(config-if)# switchport access vlan 10
  SW1(config-if)# end

On PC-1:
  IP Address     : 192.168.10.10
  Subnet Mask    : 255.255.255.0
  Default Gateway: 192.168.10.1

On PC-2:
  IP Address     : 192.168.10.11
  Subnet Mask    : 255.255.255.0
  Default Gateway: 192.168.10.1

On PC-3:
  IP Address     : 192.168.20.10
  Subnet Mask    : 255.255.255.0
  Default Gateway: 192.168.20.1

                  COMPLETE PACKET TRACER INITIALIZATION SCRIPTS

--- COPY-PASTE CLI SCRIPT FOR ROUTER (R1) ---
NOTE: For Cisco 1941/2901/2911 routers, use 'GigabitEthernet0/0'. 
      For Cisco 4331 routers, use 'GigabitEthernet0/0/0'.

enable
configure terminal
hostname R1

interface GigabitEthernet0/0
 no shutdown
 exit

interface GigabitEthernet0/0.10
 encapsulation dot1Q 10
 ip address 192.168.10.1 255.255.255.0
 exit

interface GigabitEthernet0/0.20
 encapsulation dot1Q 20
 ip address 192.168.20.1 255.255.255.0
 exit

end
write memory


--- COPY-PASTE CLI SCRIPT FOR SWITCH (SW1) ---
enable
configure terminal
hostname SW1

vlan 10
 name Sales
 exit

vlan 20
 name Engineering
 exit

interface FastEthernet0/1
 switchport mode access
 switchport access vlan 10
 no shutdown
 exit

interface FastEthernet0/2
 switchport mode access
 switchport access vlan 10
 no shutdown
 exit

interface FastEthernet0/3
 switchport mode access
 switchport access vlan 20
 no shutdown
 exit

interface FastEthernet0/10
 switchport mode access
 switchport access vlan 10
 no shutdown
 exit

interface FastEthernet0/24
 switchport mode trunk
 no shutdown
 exit

end
write memory
