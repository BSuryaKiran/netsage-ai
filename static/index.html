Level-0 Deterministic Rule Checker

Rule-based pattern matcher for immediate Cisco configuration errors

The Level-0 checker executes locally with zero external API dependencies. It inspects Cisco show-command outputs against validated network rules (e.g. VLAN mismatch, Gateway mismatch, IP duplication, Interface shutdown) to provide instantaneous deterministic flags.

Responsible AI Principles

Safety, transparency, and human-in-the-loop controls

  • Mandatory Human Review: All AI recommendations are strictly advisory and require human confirmation.
  • No Automatic Configuration: NetSage AI never executes live configuration commands on devices.
  • Fallback Transparency: If Gemini is unavailable, output is explicitly labeled as LEVEL-0 FALLBACK.
  • Traceable Audit Logging: Every diagnostic attempt and review decision is logged with zero secret exposure.
